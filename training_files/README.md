# Training FastText Models (Old)
As mentioned in `./README.md`, we initially trained [FastText](https://fasttext.cc/) models on our Ancient Greek corpus. 
Currently, we shifted our focus to training BERT-based models. If you're interested in learning about FastText itself, we composed 
a quick [document](https://drive.google.com/file/d/1Wc9fJ721DeDBIcGOg2gEwUHzxoFsOoSb/view?usp=sharing) that goes over the main 
points and some resources that should help guide you!

## Explanation of Files
`train.py` is the script that uses the FastText library to create and train the models given a set of hyperparameters. It reads
the hyparameters from the `input_arguments.txt` file. Each line in this text file defines a complete set of hyparameters to train
a model; each line is formatted in the following way:
``
Learning Rate, Embeddings' Dimension, Window Size, Number of Epochs, minc, minn, maxn, negative sampling rate, word n-grams.
``
You can visit the [FastText website](https://fasttext.cc/docs/en/python-module.html#train_unsupervised-parameters) to understand 
what each of these hyperparameters mean.

You'll notice that there are 10 lines in `input_arguments.txt`, and that's because we're utilizing 
[job arrays](https://github.com/guru-desh/Intro-To-PACE-ICE#about-job-arrays) to call the `train.py` script multiple times in one 
go. This way, we don't have to wait for a couple of hours for a single model to be trained.

In `train.sh`, we made sure that whenever we call the `train.py` script, we automatically copy the `input_arguments.txt` file into
a folder that holds all of the trained model from the current batch trained and generate a similarity matrix for the model that 
was just done training. Later, once all of the models in the batch were trained, we call `after_train.py` script in `whole.sh`. 
`after_train.py` reads the loss values generated by the `train.py` script and records how each model performed by updating a dictionary `hyparameters -> loss values` and dumping it into a pickle file.
`after_train.py` also creates a loss graph and saves it in a folder dedicated to the model that was just trained. Later, we can 
call `helper_file.py` to read the pickle file updated by `after_train.py` and get the top-`k` set of hyparameters that performed 
well so far in the history of all the trainings done.

## How to Run
Once you've logged into PACE-ICE and inputted all the 10 sets of hyperparameters into `input_arguments.txt`, type the following 
command in your shell:

```sh
. whole_train.sh
```
